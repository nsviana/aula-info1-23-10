Atividade CSS: Clube da Leitura

Crie um pequeno site de resenhas de livros. A página inicial apresenta o clube e recomenda leituras; o menu lateral conduz a páginas complementares, cada uma dedicada a um livro. Primeiro construa as páginas em HTML. Depois, use uma folha CSS externa para dar unidade ao site.

Questão — Website Clube da Leitura

Objetivo

Monte um site composto por uma página inicial e duas páginas de resenha. Todas devem compartilhar o mesmo cabeçalho, menu lateral, área de conteúdo e rodapé. O menu deve permitir chegar a cada livro e retornar à página inicial.

  • Crie index.html como página inicial e dois HTML para as resenhas.
  • Inclua no menu links para Início, Livro 1 e Livro 2.
  • Em cada resenha, escreva sinopse breve, opinião da dupla, gênero e indicação de público leitor.
  • Use uma imagem de capa ou um espaço reservado com texto alternativo.
  • Crie e vincule uma folha externa chamada estilo.css.
  • Inclua um detalhe formatado com o atributo style inline no HTML.
  • Altere o conteúdo HTML e as regras CSS nos desafios finais.
A meta é praticar caminhos de links entre arquivos, repetir uma estrutura em outras páginas e perceber como CSS externo muda o visual do site inteiro.

Estrutura de pastas

Organize os arquivos assim

As duas resenhas ficarão dentro da pasta livros. Repare que o endereço para o CSS e para a página inicial muda quando o HTML está dentro dessa pasta.

clube-da-leitura/ index.html estilo.css livros/ livro-1.html livro-2.html
Na página inicial, o link para a resenha pode ser livros/livro-1.html. Em uma resenha, o link de volta é ../index.html.

Modelo visual da página inicial

Elementos que devem aparecer

A primeira página deve ter a mesma organização visual mostrada ao lado. Os textos, livros, cores e imagens podem ser escolhidos pela dupla.

  • Cabeçalho principal: nome do site ou do clube.
  • Menu lateral: Início e links para as duas resenhas.
  • Título do conteúdo: por exemplo, “Leitura em destaque”.
  • Conteúdo: capa, apresentação e chamada para ler a resenha.
  • Rodapé: crédito do projeto ou nomes da dupla.
No primeiro momento, replique o exemplo simples. Depois, personalize o site com o HTML e o CSS.

    Etapas da atividade

    Parte 1 — HTML e navegação

    1. Crie os arquivos e pastas conforme a estrutura indicada.
    2. Monte o cabeçalho, o menu, o título, o conteúdo e o rodapé da página inicial.
    3. Crie as páginas Livro 1 e Livro 2 repetindo a estrutura.
    4. Troque os links para apontarem aos arquivos corretos. Teste todos no navegador.
    5. Acrescente informações próprias: título do livro, autoria, gênero, sinopse e opinião.

    Parte 2 — CSS externo

    1. Crie estilo.css e conecte-o no <head> de cada página.
    2. Use caminhos relativos: estilo.css na raiz e ../estilo.css dentro de livros.
    3. Defina fonte, cor de fundo, cores dos textos, bordas e espaçamento.
    4. Formate o menu para ficar lateral e o rodapé para aparecer abaixo do conteúdo.
    O exemplo completo em HTML está no projeto inicial em projeto-inicial/. Ele começa sem CSS vinculado, para que você faça essa ligação como parte do exercício.

    Questões e alterações finais

    Modifique o CSS e o próprio HTML

    1. Cores e fontes · CSSEscolha novas cores para fundo, cabeçalho e links. Troque a fonte dos títulos e dos parágrafos.
    2. Bordas · CSSAltere cor, espessura e estilo das bordas do cabeçalho, menu e rodapé. Depois experimente remover uma delas.
    3. Menu lateral · CSSAltere largura, alinhamento, espaçamento e cor dos itens do menu. O menu continua claro e fácil de usar?
    4. Uma terceira resenha · HTMLCrie mais um arquivo HTML de livro. Acrescente o novo link no menu de todas as páginas e teste os caminhos.
    5. Conteúdo e ordem · HTMLTroque o texto de apresentação, acrescente uma seção “Nossa opinião” e reorganize o conteúdo com títulos e parágrafos.
    6. Rodapé · HTML + CSSInclua os nomes da dupla no HTML e ajuste a aparência do rodapé no CSS externo.
    Confira antes de entregar: todas as páginas abrem; o menu leva aos destinos certos; o visual é consistente; as mudanças de estilo estão no arquivo CSS; há um exemplo de estilo inline no HTML.
